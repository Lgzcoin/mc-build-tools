# MC 建造 / 创作工具（mc-build-tools）

面向「造东西」的工具：指令、形状、地图画、材料清单。

## 已收录
- `tools/指令生成器.html` — fill / setblock / clone / execute 可视化生成，坐标换算，历史记录（浏览器打开，纯本地）

## 计划收录
- 圆形 / 球形 / 椭球 / 拱门坐标生成器，导出为命令或建筑脚本
- 图片转地图画（128×128，输出 .dat 或放置命令）
- 材料清单计算器（按建筑尺寸估算方块、潜影盒、挖掘量）
- 结构投影辅助（半透明预览 + 材料清单）

## 约定
- 优先做单文件 HTML（零安装、跨平台）或独立客户端模组
- 不联网、不依赖服务端
